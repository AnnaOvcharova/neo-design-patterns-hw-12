# Домашка - Фінальний проєкт

# «Генератор резюме з JSON‑опису»

## Опис завдання

У цьому фінальному домашньому завданні необхідно реалізувати генератор резюме, який демонструє застосування п'яти патернів проектування: Facade, Template Method, Factory Method, Composite, Decorator.

Завдання має на меті навчити вас:

- Правильно застосовувати патерни проектування в практичних сценаріях
- Створювати модульну, розширювану архітектуру
- Структурувати код з використанням патернів

Необхідно сформувати самодостатню HTML‑сторінку‑резюме, яка будується з єдиного джерела даних — файл `resume.json`. Усі стилі фіксовані у `styles.css`, сторонніх бібліотек або фреймворків не використовуємо. Після компіляції `main.ts` і відкриття `index.html` сторінка повинна безпомилково відобразити повне резюме, а проєкти з прапорцем `"isRecent": true` — підсвітити червоним.

```
    │   ├── AbstractImporter.ts # Базовий Template Method
    │   └── ResumeImporter.ts   # Конкретна реалізація
    ├── blocks/                 # Конкретні блоки резюме
    │   ├── BlockFactory.ts     # Factory Method
    │   ├── HeaderBlock.ts
    │   ├── SummaryBlock.ts
    │   ├── ExperienceBlock.ts  # Composite‑контейнер
```

## Запуск проекту

1. Встановлення залежностей:

   ```bash
   npm install
   ```

2. Режим розробки:

   ```bash
   npm run dev
   ```

3. Збірка для продакшену:

   ```bash
   npm run build
   ```

4. Попередній перегляд збірки:
   ```bash

   ```

## Патерни проєктування

1. **Facade (`ResumePage.ts`):** Надає простий високорівневий інтерфейс для клієнтського коду, приховуючи складну логіку завантаження даних, парсингу через імпортер, генерації окремих блоків та їх рендерингу в DOM.
2. **Template Method (`AbstractImporter.ts` та `ResumeImporter.ts`):** Визначає кістяк алгоритму завантаження та валідації JSON-даних у базовому класі, делегуючи конкретні кроки підкласу.
3. **Factory Method (`BlockFactory.ts`):** Інкапсулює логіку створення відповідних класів-блоків на основі типу даних секції резюме.
4. **Composite:** Блоки резюме реалізують єдиний інтерфейс відображення, що дозволяє працювати з деревоподібною структурою секцій та елементів одноманітно.
5. **Decorator (`HighlightDecorator.ts`):** Динамічно додає додаткову функціональність (стиль підсвічування `.highlight` / червоний колір) до блоків з прапорцем `"isRecent": true`, не змінюючи вихідний клас блоку.

## Як додати новий блок (наприклад, Certificates)

1. Створити новий клас у папці `src/blocks/CertificatesBlock.ts`, який реалізує інтерфейс блоку резюме та повертає відповідну HTML-розмітку.
2. У файлі `src/blocks/BlockFactory.ts`:
   - Імпортувати новий клас `CertificatesBlock`.
   - Додати нову гілку `case 'certificates':` (або відповідну умову), яка повертає екземпляр `new CertificatesBlock(...)`.
3. Додати відповідні дані у файл `resume.json`.
